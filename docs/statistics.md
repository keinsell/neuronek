# Statistics

Polars - This is arguably the most powerful and popular data analysis library in Rust:
Lightning-fast DataFrame library written in Rust
Similar to pandas but with much better performance (up to 50x faster)
Supports parallel execution and efficient memory usage
Handles common data formats (CSV, JSON, Parquet, etc.)
Has excellent DataFrame manipulation capabilities
smartcore - A comprehensive machine learning library:
Implements various ML algorithms
Supports linear algebra operations
Good for statistical analysis
Native Rust implementation
ndarray - For numerical computing:
N-dimensional array operations
Linear algebra functionality
Similar to NumPy in Python
Good for mathematical operations on data
statrs - Statistical computations:
Probability distributions
Statistical functions
Hypothesis testing
Descriptive statistics
linfa - Machine learning framework:
Modular design
Various ML algorithms
